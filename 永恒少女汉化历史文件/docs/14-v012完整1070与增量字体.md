## 4. 旧 PC 译文人工修正

虽然本场自动对齐为 100%，但整场人工读取仍发现若干旧 PC 译文自身的问题，因此不直接原样照搬。

代表性修正：

```text
外辺に抉りこむような通路
```

旧译误成“通往外部的通道”，实际是外侧墙体向内凹入般的通道，Switch 版修正空间关系。

另外修正：

```text
「そう……」
-> 「这样啊……」

「何も。……何もわからないわ」
-> 「什么都不记得。……什么都不知道」

“话中意”
-> “这句话的意思”
```

并恢复：

```text
その人自身にも
```

所表达的“温柔的人自己也会喜欢那样的自己”这一反身含义。
