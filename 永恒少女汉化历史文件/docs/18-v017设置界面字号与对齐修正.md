# 《永恒少女》NS 汉化阶段 18：v017 设置界面字号与对齐修正

## 1. 修正目标

v006a 实机复测后，设置界面的缺字问题基本消失，但仍存在：

```text
部分字号不统一
基线不统一
同列文字左右起点不齐
按钮中文字大小不统一
```

此前这些被登记为非阻断视觉问题。全文本阶段完成后，本阶段正式回收该问题。

---

## 2. 根因

旧版 `04_scripts/localize_settings_images.py` 使用 `fitted_font()` 针对每一条中文单独适配字号：

```text
中文宽度 ← 当前日文原文字框宽度
中文高度 ← 当前日文原文字框高度
```

然后再把中文居中到该日文文字框。

这会产生两个直接结果：

1. 同一层级的短中文可以使用很大的字号，长中文却被单独缩小。
2. 左列/右列文字虽然属于同一个列表，但会因日文原文宽度不同而改变中文起点。

实际测量旧 v006a 输出可见：

```text
类型             原版文字高度       旧中文高度
页标题           约 54～57 px        约 38～41 px
普通设置项       约 30～32 px        常见 35～43 px
按钮文字         约 25～29 px        常见 35～39 px
```

也就是“标题偏小、正文/按钮反而偏大”，与实机反馈一致。

---

## 3. v017 排版规则

本次删除每条文本独立自适应字号的做法，改为固定视觉层级：

```text
页标题                  58 px，center x=960
分组标题                34 px，left x=104
ADV 设置页紧凑正文      26 px
普通设置正文            30 px
说明 note               28 px
普通状态按钮            28 px
0008 特殊棕/红按钮族     22 px
```

正文不再以每条日文文字框中心为水平基准，而是使用原版布局测得的固定 x 锚点：

```text
Page 1   left 86     right 1079
Page 2   left 87     right 972
Page 3   left 87     right 1007
Page 4   left 87     right 1007     paragraph 516
Page 5   paragraph 376
Page 6   left 258    paragraph 345
Page 7   paragraph 247
```

因此同一列中的中文起始位置保持稳定，长说明文字也沿用统一的段落左起点。

## 9. 实机测试重点

静态 QA 已经确认字体大小层级、基线和列锚点符合预设，但图片最终观感仍需要 Switch 实机确认。

建议重点观察：

```text
系统 / 显示 / 消息1 / 消息2 / 声音 / 语音页标题大小是否协调
左右两列项目的左边缘是否整齐
消息2 的多行长说明是否呈现统一起点
使用 / 不使用、显示 / 不显示等按钮文字是否大小一致
小尺寸渐变/阴影状态按钮是否有压边
中文与原版其他 UI 元素之间是否保持合理留白
```

如果实机视觉确认正常，则此前 v006a 登记的“字号/基线/排布不齐”问题可以正式关闭。
