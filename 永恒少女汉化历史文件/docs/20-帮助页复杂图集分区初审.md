# 《永恒少女》NS 汉化阶段 20：帮助页复杂图集分区初审

## 1. 对象

当前仍未安全处理的主要复杂图片 UI：

```text
System/help01.png ～ help11.png
System/menuhelp.png
System/menuhelp_a.png
```

`help01～11` 全部为：

```text
1920 × 1080
```

且文件体积约 3～10 MiB，属于完整帮助页/示意截图复合图，不是普通单行按钮精灵。

---

## 2. 整图 OCR 结论

直接对整张图运行 MangaOCR 会把：

```text
左侧操作说明
右侧游戏截图内的对白/菜单
背景装饰
控制器图标
```

混在一起，输出大量与实际帮助文字无关的内容。

因此明确禁止：

```text
整图 OCR -> 直接翻译 -> 覆盖原图
```

---

## 3. 网格探测结果

以 `help01.png` 做 3×3 网格探测后：

```text
左列  x≈0～640      能稳定识别真正的帮助标题/功能名
中列 / 右列          主要识别到示意截图中的噪声文本
```

稳定识别出的真实帮助词包括：

```text
操作方法
タイトルメニュー
ゲームの進め方
システムメニュー
セーブ／ロード
システム設定
クイックメニュー
バックログ
```

因此确定帮助页共享的第一层版式：

```text
左侧 = 说明/目录区
右侧 = 示意截图区
```

## 5. 当前结论

左栏分区显著减少了右侧截图噪声，但 800×270 的区块仍然过大，MangaOCR 会发生：

```text
跨行拼接
标题与说明混合
少量截图边缘文字串入
长段落误识别
```

因此目前仍不足以安全生成中文帮助图。

下一步应在左栏内继续做 **行级 / 段落级区域定位**，而不是继续扩大 OCR 模型或直接人工猜测全文。

推荐流程：

```text
1. 用颜色/连通块确定真实文字行 bbox
2. 对单行或单段小裁图 OCR
3. 与游戏现有 Config/button.datu8 中文术语交叉验证
4. 建立 help01～11 的逐块翻译表
5. 只清理对应文字 bbox，右侧示意截图保持原样
6. 做非目标像素与 Alpha QA
```

在完成第 1～3 步前，帮助页继续保持原资源，避免低可信修改进入测试包。
