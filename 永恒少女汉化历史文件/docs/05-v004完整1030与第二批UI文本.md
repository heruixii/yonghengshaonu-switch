## 4. 图片 UI 安全映射

用户明确要求标题按钮、菜单图片等 UI 也必须汉化，因此图片 UI 仍是正式发布硬门槛。

当前已进一步确认：

```text
System/title_menu.spm = SPM VER-2.02
SPM 明确引用 title_btn0001～0009、0101～0109、0208
公开标题截图与本地 title_btn 资源像素模板可匹配，确认属于同一套标题按钮资源
System/systemmenu.png / systemmenu_a.png 与 systemmenu.spm 属于系统菜单图集族
```

同时发现：

```text
title_btn0003.png 实际画布为 672x672
但 SPM 对其使用约 283x85 的裁切区域
```

说明不能仅按图片尺寸或文件编号猜测含义。

目前模板匹配能定位标题截图中的多个按钮区域，但不同按钮共享大量边框像素，标签特征分数过于接近，尚不能达到“文件编号 → 日文标签”零猜测绑定。

因此 v004 **没有**为了追求表面进度而随意把中文烤进 `title_btn*.png`。

已建立安全映射表：

```text

```

未精确绑定的 PNG 标记为：

```text
unresolved-safe-hold
```

只有绑定证据足够后才允许改图。图片 UI 任务没有取消，仍属于正式发布门槛。
