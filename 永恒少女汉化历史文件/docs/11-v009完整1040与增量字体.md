## 6. 运行时字体增量扩充

1040 新增译文对 v008 三个运行时 TTC 引入少量新缺字。

主要新增字符包括：

```text
冻 吓 嘟 囔 揪 灭 热 犷 瘪 窝
纱 绍 绕 讽 诘 谎 谴 违 钻 雾
顽 飞 驳 鲠 鸦
```

增量脚本：

```text
04_scripts/extend_runtime_fonts.py
```

处理原则：

```text
从 v008 已修复 TTC 开始
只补当前累计文本真正缺失的码点
微软雅黑作为字形来源
先展开复合字形为纯轮廓
按 UPM 2048 -> 1024 缩放
保持旧 glyph 顺序不变
保持旧 cmap / hmtx / vmtx / glyf 不变
```

三个 TTC 新增码点：

```text
dfgotp5.ttc  25
dfhsr4.ttc   25
dfmrg5_u.ttc 23
```

累计 source + translation 需要覆盖的非 ASCII 码点：

```text
2308
```

最终 3 TTC × 3 face：

```text
missing = 0 / 0 / 0
```
