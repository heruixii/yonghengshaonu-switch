# 《永恒少女》NS UI 汉化范围与执行清单

## 1. 目标

UI 汉化与剧情汉化并行推进，属于正式发布硬门槛。

最终目标不是“能看懂剧情即可”，而是正常玩家操作路径中的功能性 UI 尽量完整简体中文化，包括标题、菜单、按钮、设置、存读档、系统提示和 Extra 模式。

不允许以“图片不好改”为理由保留大量日文按钮，也不允许把内部资源名误当成玩家可见文字去修改。

---

## 2. 已确认的 UI 资源类型

Switch 版 UI 同时包含两类：

```text
A. BINU8 / DATU8 中的动态文字
B. System/*.png 中已经烘焙进图片的文字和按钮标签
```

两者都必须处理。

## 5. UI 翻译原则

UI 采用简洁、统一、符合 Switch 操作习惯的中文。

优先统一以下术语：

```text
保存
读取
设置
系统
返回标题
历史记录
自动
跳过
快速保存
自动保存
回想
事件
CG鉴赏
音乐鉴赏
角色鉴赏
确认
取消
返回
默认设置
```

人物名、世界观词、功能词必须进入统一术语表，避免剧情、菜单、CG 页面各用一套译名。

---

## 6. 图片修改规则

所有图片修改必须：

```text
保持原始像素尺寸
保持 PNG 透明通道
保持原文件名和目录
保持按钮不同状态的画布位置一致
不裁切原 UI 边框和点击区域
中文尽量沿用原视觉层级、字号关系、对齐方式
```

如果原按钮是多状态图集，需要修改完整状态集合，不只改默认状态。

```text
功能性图片日文中文化
```

正常游玩路径中发现的日文残留必须被分类为：

```text
需要修复

```

不得以未分类状态带入正式发布。
