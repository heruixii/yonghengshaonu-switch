## 2. 标题菜单补全

此前 v007 只处理标题前四项。本阶段对独立 `title_btn` 状态图逐张识别，确认并补齐：

```text
0005 / 0105    CG鑑賞       -> CG鉴赏
0006 / 0106    シーン鑑賞    -> 场景鉴赏
0007 / 0107    音楽鑑賞      -> 音乐鉴赏
0008 / 0108    EXシナリオ    -> EX剧情
0009 / 0109    タイトルに戻る -> 返回标题
0208           EXシナリオ    -> EX剧情（灰色禁用态）
```

`0208` 的文字不是白色，而是 RGB 约 `(89,89,89)` 的禁用灰态。生产脚本使用 `0008` 的同位置字形掩膜清理旧字，再以灰色重绘，Alpha 保持逐像素不变。

生产脚本：

```text

```
