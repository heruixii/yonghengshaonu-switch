## 3. 图像处理方式

生成脚本：

```text
04_scripts/localize_settings_images.py
```

主设置页的正文标签实际为白色 RGB + Alpha 抗锯齿文字层。

处理原则：

```text
只移除目标文字区域内的白色 Alpha 像素
不修改棕色分隔线
不修改面板/滑条/装饰图形
使用游戏 RomFS 自带 TTC 字体重新绘制中文
保持原 PNG 尺寸和 RGBA 模式
```

按钮精灵属于不透明底图，不能直接把白字像素改透明，因此使用目标文字框左右两侧原始背景逐行插值，先重建文字下方背景，再绘制中文。

`configmenubutton_0008.png` 属于独立棕红配色族，通过比较同视觉状态下的不同文案，确认文字区域稳定位于每个 43px 状态块中的：

```text
x ≈ 52 ～ 198
y ≈ 8 ～ 35
```

普通态文字使用原图深棕色，选中态使用原图红棕色。
